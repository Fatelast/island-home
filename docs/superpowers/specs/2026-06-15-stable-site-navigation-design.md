# 顶部导航稳定切换设计

## 问题

页面导航使用完整文档跳转。每个新页面加载后，`pageMotion.ts` 都会让
`.site-header` 从上方 18px、透明度 0 重新进入，导致固定操作区域明显跳动。
导航链接还同时使用 CSS 与 GSAP hover 位移，存在重复控制。

## 设计

- 顶部导航不参与页面进入动画，加载后直接保持最终位置和透明度。
- 页面标题、内容卡片继续保留现有进入动画。
- 导航链接仅使用 `SiteHeader.astro` 内的 CSS hover、active、focus 反馈。
- 全局 GSAP 继续管理页面操作按钮和内容卡片的 hover 动画。
- 不引入客户端路由或 View Transitions，保持当前静态站点导航架构。

## 验收

- 点击任意顶部导航项后，新页面的 Header 首帧与稳定帧位置一致。
- 活动项宽度与其他导航项一致，不引发布局变化。
- 鼠标 hover、按压和键盘焦点反馈仍然存在。
- 降低动效模式行为不退化。
