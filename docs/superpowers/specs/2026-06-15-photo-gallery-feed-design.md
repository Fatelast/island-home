# 海风相册信息流与灯箱设计

## 1. 目标

重新设计海风相册的信息流与交互，使其适合长期积累数百张不同尺寸、不同画幅的相机照片。

核心目标：

- 信息流完整保留照片原始宽高比，不在列表阶段裁切。
- 支持任意画幅，兼容常见横片、竖片、方片和超宽全景照片。
- 默认突出照片，按需渐进展示拍摄信息。
- 支持按拍摄时间归档、静态分页和连续加载。
- 点击照片后通过全屏灯箱查看大图和完整元信息。
- 保持 Astro 静态站点的首屏性能、SEO 和无 JavaScript 可用性。

非目标：

- 本阶段不引入后端、数据库、用户上传或后台管理。
- 本阶段不提供地点、设备、标签等多维组合筛选。
- 本阶段不处理图片 CDN 上传和自动转码服务，只预留数据与响应式图片接口。

## 2. 信息架构

### 2.1 页面结构

相册页从上到下分为：

1. 页面标题区：保留“摄影索引”“海风相册”和简短说明，并压缩标题区与照片流之间的留白。
2. 时间归档区：展示“全部”、年份和当前年份对应的月份。
3. 照片信息流：使用保留原始比例的增强型瀑布流。
4. 分页区：提供“加载更多”和可访问的传统下一页链接。
5. 灯箱：点击照片后在当前页面覆盖展示。

### 2.2 信息层级

照片卡片默认展示：

- 缩略图
- 标题
- 拍摄日期

桌面端悬停或键盘聚焦后补充展示：

- 拍摄地点
- 相机
- 镜头
- 查看大图提示

触屏设备不依赖悬停。点击照片直接打开灯箱，完整元信息在灯箱中展示。

## 3. 路由与归档

采用静态归档路由，避免通过查询参数动态组合大量状态：

```text
/island/photos/
/island/photos/page/2/
/island/photos/2026/
/island/photos/2026/page/2/
/island/photos/2026/05/
/island/photos/2026/05/page/2/
```

规则：

- 根路由按拍摄日期倒序展示全部照片。
- 年份路由展示指定年份的照片。
- 月份路由展示指定年月的照片。
- 每页默认 30 张，可根据真实缩略图体积在 24 至 36 张之间调整。
- 归档筛选使用真实链接，刷新、分享、前进和后退均可恢复状态。
- 每个 HTML 分页同时生成对应的静态 JSON 数据文件；HTML 用于直接访问和无 JavaScript 降级，JSON 仅用于“加载更多”。
- “加载更多”在 JavaScript 可用时获取下一页 JSON 并追加；同时使用 `history.pushState` 更新对应的 HTML 分页 URL。
- 无 JavaScript 时，“加载更多”退化为普通的下一页链接。
- 返回页面时优先由浏览器滚动恢复机制恢复位置；增强脚本只记录已追加页数，不自建复杂滚动状态系统。

## 4. 瀑布流布局

### 4.1 基础规则

- 每张照片使用 `width` 和 `height` 计算真实 `aspect-ratio`。
- 信息流不裁切照片，图片使用完整内容尺寸。
- JavaScript 增强状态使用 CSS Grid 和按真实比例计算的行跨度实现瀑布流，保持 DOM、键盘和读屏顺序与拍摄时间顺序一致。
- 无 JavaScript 时退化为普通响应式网格，照片仍保持完整比例，只是不消除不同行高产生的空隙。
- 桌面端根据容器宽度显示 3 至 4 列。
- 平板端显示 2 列。
- 移动端显示 1 列。
- 列间距保持稳定，避免照片尺寸变化带动其他卡片横向抖动。

### 4.2 全景照片

当 `width / height >= 2.4` 时，将照片标记为全景图：

- 宽屏桌面端跨两列。
- 窄屏或两列布局中占满当前行宽度。
- 移动端保持单列完整比例。

全景判定由纯函数完成，后续可通过显式数据字段覆盖自动结果，但第一版不增加手工配置。

### 4.3 占位与失败状态

- 图片加载前使用 `aspect-ratio` 预留准确空间，避免累计布局偏移。
- 没有缩略图时显示现有岛屿配色占位图，并保留原始比例。
- 图片加载失败时切换到同一占位状态，不移除卡片，也不改变尺寸。

## 5. 灯箱交互

灯箱通过点击照片卡片打开，支持：

- 完整显示当前照片，不裁切。
- 上一张、下一张和关闭。
- 键盘 `ArrowLeft`、`ArrowRight` 和 `Escape`。
- 显示标题、日期、地点、相机、镜头、当前序号和总数。
- 打开时将焦点移入灯箱并锁定背景滚动。
- 关闭时恢复触发卡片的焦点和原页面滚动位置。
- 首次打开只加载当前原图；随后预加载相邻一张，避免一次请求全部原图。
- 图片加载期间保持稳定画布并显示轻量加载状态。
- 到达当前已加载批次末尾时，如仍有下一分页，可先加载下一批再继续切换。

灯箱切换采用短距离横向过渡。动画不改变容器尺寸，避免切换横竖片时页面跳动。

## 6. 动效与反馈

### 6.1 信息流

- 首批照片进入视口时分批淡入并轻微上移。
- “加载更多”后的新照片单独播放进入动画，已有照片不重复播放。
- 桌面端悬停时缩略图轻微放大，信息层从底部渐入。
- 不使用大幅 3D 倾斜、翻转或会干扰摄影内容的装饰动画。

### 6.2 减少动画

在 `prefers-reduced-motion: reduce` 下：

- 关闭位移、缩放和横向切换动画。
- 保留即时的显隐、焦点和加载反馈。

所有高频动画仅使用 `transform` 和 `opacity`，避免布局抖动。

## 7. 数据模型

照片数据继续使用静态 TypeScript 配置：

```ts
interface PhotoItem {
  id: string;
  title: string;
  alt: string;
  location: string;
  date: string;
  camera: string;
  lens: string;
  width: number;
  height: number;
  thumbnail?: string;
  thumbnailSources?: {
    src: string;
    width: number;
    type?: 'image/avif' | 'image/webp';
  }[];
  original?: string;
  color: 'teal' | 'gold' | 'pink' | 'green';
}
```

约束：

- `id` 在全部照片中唯一，用于灯箱定位和 URL 状态。
- `date` 使用 `YYYY-MM-DD`，年份和月份在构建阶段派生。
- `width`、`height` 必须填写原片或缩略图对应的真实比例尺寸。
- `thumbnail` 只用于信息流。
- `original` 只在灯箱打开后加载。
- 中文展示文本继续通过现有 `t(locale, '中文原文')` 反查国际化 key。
- 摄影作品标题、地点、设备等个人内容不要求提供英文翻译，按既定国际化范围保留原文。

## 8. 组件边界

### 8.1 `PhotoGallery`

React island 的顶层组件，负责：

- 接收当前归档和分页的服务端初始数据。
- 管理已追加照片和当前分页。
- 协调卡片、加载更多和灯箱状态。
- 更新浏览器历史 URL。

初始照片必须由 Astro 服务端渲染，避免客户端 JavaScript 未加载时出现空白。

### 8.2 `PhotoArchiveFilter`

负责年份和月份链接：

- 使用真实 `<a>` 路由，不依赖客户端状态。
- 标识当前归档。
- 在移动端允许横向滚动，不压缩文字。

### 8.3 `PhotoCard`

负责单张照片：

- 按真实宽高比预留空间。
- 渲染响应式缩略图或占位图。
- 展示摘要和渐进元信息。
- 提供键盘可访问的灯箱触发入口。
- 根据画幅判定结果增加全景样式标记。

### 8.4 `PhotoLightbox`

负责：

- 当前照片与前后索引。
- 原图按需加载和相邻预加载。
- 键盘操作、焦点锁定和焦点恢复。
- 背景滚动锁定。
- 元信息展示和加载失败状态。

### 8.5 构建期工具

新增纯函数工具负责：

- 按日期倒序排序。
- 生成年份和月份归档。
- 分页切片。
- 计算全景判定。
- 生成 HTML 分页与加载更多使用的静态 JSON 数据。

这些函数不依赖 DOM，便于单元测试。

## 9. 渐进增强与错误处理

- 首批照片和传统分页链接必须在无 JavaScript 状态下可用。
- JavaScript 增强失败时，不阻止用户进入下一静态分页。
- 单张缩略图或原图失败不影响其他照片浏览。
- 灯箱原图失败时显示错误状态，并保留上一张、下一张和关闭操作。
- 下一分页请求失败时保留当前内容，并允许用户重试或通过普通链接进入下一页。
- 空归档页面展示明确空状态和返回“全部照片”的链接。

## 10. 测试与验收

### 10.1 单元测试

覆盖：

- 日期倒序排序。
- 年份和月份归档。
- 30 张一页的分页边界。
- 空数据和最后一页。
- `width / height >= 2.4` 的全景判定。
- 灯箱上一张、下一张的索引计算。

### 10.2 构建验证

- `npm run test`
- `npm run build`
- 验证根相册页、年份页、月份页和分页路由均生成成功。
- 验证照片数据中文文案可由现有国际化反查机制处理。

### 10.3 浏览器验收

桌面端与 375px 移动端验证：

- 横片、竖片、方片和全景图均完整显示。
- 无横向滚动和卡片重叠。
- 图片加载前后无明显布局跳动。
- 年/月链接和分页 URL 可刷新、分享、前进和后退。
- 加载更多只动画新增照片。
- 灯箱支持鼠标、触摸和键盘。
- 焦点不会逃出灯箱，关闭后回到原照片。
- 原图和下一页请求失败时仍可继续操作。
- 减少动画模式下不播放位移和缩放动画。

## 11. 实施范围

第一阶段实施：

- 数据模型扩展和构建期归档工具。
- 静态年份、月份和分页路由。
- 增强型瀑布流。
- 全景跨列。
- 加载更多渐进增强。
- 全屏灯箱。
- 占位图、失败状态、键盘和减少动画支持。

后续再考虑：

- 地点、设备和标签组合筛选。
- 图片 CDN、自动转码和自动读取 EXIF。
- 影集主题、收藏、分享和照片详情页。
- 数量增长到数千张后的虚拟化或独立图片索引服务。
